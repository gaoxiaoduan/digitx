# 0005. 前端分页优化大数据量渲染卡顿

* 状态: 已接受
* 日期: 2026-07-27

## 背景与问题

当域名数据库包含大量数据（例如 > 10,000 条）时，前端全量渲染 DOM 节点会导致严重的页面布局重排卡顿，甚至导致浏览器标签页假死。

## 决策驱动因素

* 过多的 DOM 节点严重影响表格渲染性能与交互响应时间。
* 域名淘金用户需要精准的位置控制感、明确的筛选条数统计与稳定的视觉体验。
* 虚拟滚动在快速拖拽极长滚动条时存在定位精度变差和视口闪烁白块问题。

## 备选方案

1. 全量 DOM 渲染（原方案）
2. 虚拟滚动（使用 `@tanstack/react-virtual` 窗口化渲染）
3. 基于 `shadcn/ui` 的前端分页渲染（选中方案）

## 决策结果

选中方案：**基于 `shadcn/ui` 的前端分页渲染**。该方案将每页 DOM 节点固定在 25 / 50 / 100 行，保证 0ms 页面切换与绝对不卡顿的极致性能，同时给用户提供极强的位置指示与可控感。
