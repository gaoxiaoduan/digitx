# Triage 分流标签

各 Skill 使用五个标准的 Triage 角色。本文件将这些角色映射到本仓库 Issue 追踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 Issue 追踪器中的标签 | 含义                                    |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 Issue                   |
| `needs-info`               | `needs-info`         | 等待提交者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 规格已完整，可由无人值守 Agent 处理      |
| `ready-for-human`          | `ready-for-human`    | 需要人工开发实现                         |
| `wontfix`                  | `wontfix`            | 暂不处理/拒绝                             |

当 Skill 提到某个角色时，请使用此表右侧对应的标签字符串。
